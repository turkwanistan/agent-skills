# Research Output

Canonical persistent Markdown reports produced by `research-skill` are written to this directory.

Generated `*.md` reports are intentionally ignored by Git so research runs do not pollute the reusable skill repository. This README remains tracked to preserve and document the output location.

Default filename format:

`YYYY-MM-DD--<descriptive-topic-slug>.md`

For repeated distinct runs on the same date/topic, append `--2`, `--3`, and so on rather than overwriting an existing report unless the user explicitly requests an update.
